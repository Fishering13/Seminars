## Семинары 7 и 8

`./build/seminar7` — все шесть этапов многопоточности: ikj из семинара 6, 800×800, наивное создание потоков, флаг atomic и готовность всех потоков, ijk с четырьмя потоками, финальный ikj с hardware_concurrency(). Времена очень быстрых операций близки к разрешению часов: для сложности используются также точные счетчики и доказательства в локальном отчете.
